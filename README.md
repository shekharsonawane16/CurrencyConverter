# Currency Converter

A simple and responsive web-based Currency Converter that allows users to convert amounts between different currencies using current exchange rates fetched from an online API.

## 🔗 Live Demo

👉 [Open Currency Converter](https://shekharsonawane16.github.io/CurrencyConverter/)

## 📌 About the Project

This project was developed as a college mini project to practice frontend web development and working with external APIs.

Users can enter an amount, select the source and target currencies, and get the converted amount based on the latest available exchange rate provided by the API.

## ✨ Features

- Convert between multiple currencies
- Fetch exchange rates using an online API
- Simple and user-friendly interface
- Responsive design
- Input validation
- Displays the exchange rate
- Loading status while fetching data
- Error handling for API failures
- Supports pressing **Enter** to perform conversion

## 💱 Supported Currencies

The application currently supports:

- USD – US Dollar
- EUR – Euro
- GBP – British Pound
- INR – Indian Rupee
- JPY – Japanese Yen
- CNY – Chinese Yuan
- AUD – Australian Dollar
- CAD – Canadian Dollar
- CHF – Swiss Franc
- SGD – Singapore Dollar
- ZAR – South African Rand
